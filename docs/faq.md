# Frequently Asked Questions
-----------------------------------------------
:::caution[FAQ]
## 1. How to activate Windows/Office with KRA?
- When you successfully enter the main interface of KRA, choose 1 of the 2 functions in the tool:
+ [1] Activate Windows
+ [2] Activate Office
- Choose and enjoy!
## 2. How many days is the activation license?
- It is 180 days, when the system cannot connect to KRA, the user will reactivate it, it will automatically renew if there is Internet!
## 3. Can I use it without Internet?
- No, you cannot use it without Internet, KRA uses KMS to activate Windows/Office, which requires Internet
:::
