# Troubleshoot

:::caution[Troubleshoot]

If you have any issues with KinovRise Activator, please submit a bug to KinovRise's GitHub Repo (Issues) or to our email
- Github Repo for bug reporting: https://github.com/ranusTeam41/KinovRise-Activator-KRA-/issues
- Email: `tivinovdev@outlook.com`

- Репозиторий Github для сообщений об ошибках: https://github.com/ranusTeam41/KinovRise-Activator-KRA-/issues
